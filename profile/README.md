## What Is TSplus Remote Access

TSplus Remote Access is a remote-work helper for a small office, a training room, or a family business that keeps a few programs on one or two servers. TSplus Remote Access web portal is how most people arrive. From there they can open TSplus Remote Access remote session or a single TSplus Remote Access published program. The choice depends on whether they need the whole desk or just one tool for the hour.

TSplus Remote Access gateway sits in front of those hosts so the sign-in has one address. TSplus Remote Access server farm matters later, when a class or a busy morning needs a second host. A student can reach a lab program from home, and a colleague can open the office ledger without carrying that program on a laptop. The helper is aimed at that practical reach, for people who are allowed to use those servers.

Day to day, TSplus Remote Access web portal and TSplus Remote Access published program are what people touch. Administrators return to TSplus Remote Access gateway and TSplus Remote Access server farm when a host is full or a name needs access.
